# Личный сайт Артёма Артемьева

Статическая адаптивная страница на русском языке. Работает на GitHub Pages без сборки.

## Содержание

Знакомство, проектирование и перепланировки, четыре приложения, бег и горы, моржевание, Telegram-канал, упоминание партнёрского бизнеса в туризме, контакты и QR-коды социальных сетей.

Основной контакт: MAX, +7 908 66 22 802. Кнопка копирует номер; ссылка на номере запускает звонок. Ссылка на профиль MAX не задана, поскольку пользователь предоставил только телефон.

## Редактирование

- `index.html` — тексты, ссылки и разделы.
- `style.css` — оформление и мобильная адаптация.
- `app.js` — копирование номера и год в подвале.
- `assets/` — фотографии, QR-коды и иконка.

Фотографии взяты из публичного Telegram-канала владельца: портрет — пост 212, горы — пост 196, зимнее окунание — пост 190. Запрошенная фотография зимнего бега в наушниках из ВК пока не получена; её можно заменить в первом экране или добавить в раздел о беге.

QR-коды созданы локально и содержат прямые ссылки на соцсети. Для шрифта используется Google Fonts; без сети работает системный запасной шрифт. Формы сбора данных и аналитика отсутствуют.

## Публикация

GitHub Pages: Deploy from a branch → main → /(root). Для обновления достаточно загрузить изменённые файлы в ветку main.
