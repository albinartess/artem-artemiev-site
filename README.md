Статический сайт без сборки. Публикуется автоматически через GitHub Pages из ветки main, корневой папки. Файл CNAME связывает публикацию с доменом; сохраняйте его при обновлениях.

## Редактирование

- index.html — главная страница, услуги, три превью сайтов, приложения, увлечения и контакты.
- sites.html — отдельное портфолио из восьми сайтов с прямыми ссылками.
- style.css — основные стили и адаптация.
- portfolio.css — оформление портфолио и блока на главной.
- app.js — копирование телефона и год на главной.
- sites.js — фильтры портфолио и год в подвале.
- assets/sites/ — локальные снимки первых экранов сайтов.
- assets/ — личные фотографии, QR-коды, иконка.
- yandex_03379ed4613f56b8.html — файл подтверждения Яндекс Вебмастера.

На обеих страницах установлен счётчик Яндекс Метрики 113706061 с предоставленными владельцем настройками и метатег Яндекс Вебмастера. Форм сбора данных на личном сайте нет.
